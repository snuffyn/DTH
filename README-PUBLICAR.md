# Como publicar a D&TH Jóias no GitHub Pages

1. Crie um repositório público chamado `SEU_USUARIO.github.io`.
2. Extraia todos os arquivos deste pacote diretamente na raiz do repositório.
3. Faça commit na branch `main`.
4. Abra **Settings > Pages** no GitHub.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.

O arquivo `index.html` precisa ficar diretamente na raiz.
